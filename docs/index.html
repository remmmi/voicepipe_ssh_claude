The switchboard

Le tableau d'interrupteurs — chaque serveur a le sien.

Your SSH config is the setup

Voxtunnel reads ~/.ssh/config and gives every host with a key its own switch. Nothing to declare, nothing to duplicate. / Vos hosts SSH deviennent des interrupteurs, rien a configurer.

One master Transmission toggle

Cut every stream in one click without losing your per-host selection. Flip it back: the streams whose switch is ON return. / Coupez tout d'un clic, retablissez, tout revient.

The server hears a real microphone

Audio lands in the snd-aloop loopback card. Speech-to-text, voice assistants or Claude Code voice input record it like local hardware. / Le serveur enregistre votre voix comme un vrai micro.

Honest lights, no magic retry

A monitor glyph per host shows if the far end is ready. A dead stream flips its own switch off and tells you why. Latency is a slider, not a mystery. / Des voyants honnetes, une latence reglable.

Summon it

Installation — deux minutes, deux paquets.

server (VPS)
# from github.com/remmmi/voxtunnel/releases/latest
sudo apt install ./voxtunnel-server_*.deb
# loads snd-aloop now and at every boot - purely additive
client (your desktop)
sudo apt install ./voxtunnel_*.deb
voxtunnel
# or, without root: clone the repo, client/install.sh
no GUI needed
VPS_HOST=user@my-vps ./voxtunnel.sh --check
VPS_HOST=user@my-vps ./voxtunnel.sh
